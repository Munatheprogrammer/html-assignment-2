# HTML Assignment 2

A simple two-page website built with HTML as part of the Genesys Tech Hub Upskill 26.1 Web Development program.

## Pages

- **index.html** — Home page containing semantic elements, an about section, media elements, interactive FAQ, an embedded Google Map of Enugu, and a YouTube video embed.
- **contact.html** — Contact page containing a fully structured HTML form with various input types, dropdowns, checkboxes, radio buttons, and a message textarea.

## Concepts Demonstrated

- HTML5 Semantic Elements
- HTML Forms and Form Attributes
- Media Elements (audio, video)
- Interactive Elements (details, summary)
- iframe Embedding (Google Maps, YouTube)
- Navigation Between Webpages
